# Will You Accept My Love? 💌

A dumb little proposal project I built for fun. One question, two buttons, and one button that absolutely refuses to be clicked.

## The idea

Simple concept:

- Click **Yes** → done, works like any normal button.
- Try to click **No** → it runs away. Every single time. New spot on the screen, no warning.

Each time "No" dodges you, a new message pops up. Starts off polite, gets progressively more dramatic. Keep trying and eventually "No" just... gives up. Turns into "Yes" and stays that way.

There's technically no way to say no. That's not a bug, that's the entire feature.

## How it works

Nothing fancy here:

- No backend, no database, just a page that runs entirely in the browser
- "No" button repositions itself randomly whenever it's clicked (or hovered, depending on how mean I felt that day)
- A list of messages cycles through as the button keeps dodging
- After a set number of attempts, the button stops running, changes color/label, and just becomes "Yes"

That's it. That's the whole app.

## Why I made this

Honestly? Wanted to build something silly that still needed actual logic — positioning, state tracking, message sequencing. Turned out to be a fun little challenge to make something feel "alive" with just a few lines of JS.
